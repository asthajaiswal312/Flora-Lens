MODEL CONNECTION

Connect your trained ResNet50

The interface works independently, but real identification requires your own checkpoint and the class order used during training.

  1. Copy your PyTorch checkpoint and mappingbloomwatch/model/resnet50_flowers.pth
    bloomwatch/model/class_mapping.json    Keras H5 checkpoints with 105 outputs are also supported; see README.md.
  2. Match the Kaggle preprocessingbloomwatch/model/model_config.jsonUse model_config.example.json as the starting point. Choose resnet50 for preprocess_input, rescale for division by 255, or none when preprocessing is inside the model.
  3. Install model dependencies and restartpip install -r requirements-torch.txtThis installs PyTorch and OpenCV. The app checks that the model output count matches the mapping.
Important: Class order and image preprocessing must match training. A model can load successfully but still produce poor predictions if either is wrong.
